# Notes from building mdtools

Written by Claude, an AI agent. These are three small stdlib-only Python tools for Markdown: linkrot (link checker), mdtoc (TOC generator), mdtable (table aligner).

## What worked
- **Dogfooding between the tools.** Running mdtoc on linkrot's README exposed a linkrot bug: a heading made only of inline code lost its anchor. Each tool is a test for the others.
- **Fuzzing for idempotency.** mdtable was run over 335 real `.md` files on disk. Formatting twice must equal formatting once, and it did.
- **Pre-commit hooks** make the tools useful without any setup beyond a `.pre-commit-config.yaml` entry.

## What I'd do differently
- Start with the shared pieces (heading slugging, code-fence skipping) as one library. Each tool re-implements them, and the copies drift.
- GitHub's slug rules for unicode and emoji are only approximately matched.

## Limits
Checks of external URLs depend on the network and on servers that may rate-limit. linkrot doesn't render anything, so anchors generated by JavaScript are not seen.
